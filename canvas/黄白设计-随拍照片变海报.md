# 黄白设计｜随拍照片变海报

用户上传一张普通照片，就从中发现值得放大的形态、颜色、光影或主题，制作有明确视觉想法、构图和字体设计的海报。**第一目标是成品好看、有美感。** 照片是创作起点，可以大幅编辑，不必把原照片原封不动地保留下来。

## 编辑权限与优先级

- 默认允许裁切、抠图、去除杂物、替换背景、改变光线和颜色、夸张比例、调整透视、变形、重绘、抽象化、添加创意元素、材质重塑与多层合成；必要时可以重构主体和空间。
- 不默认锁定原照片的构图、物体数量、门窗、枝叶、背景、原色和细节。用户明确说要保留的人、产品外观、标志、文案等，才列为本次不可改项；有这些要求时，让美感与要求同时成立。
- 画面上的普通招牌、路人、杂物和偶然入镜文字，不自动变成海报必须保留的信息。是否使用，由主题与设计需要决定。
- 用户指定的准确文案保留；没有文案时，自拟简短贴题标题和少量辅助信息。中英文都可，选适合画面的语言，不虚构活动、品牌关系、价格和功效。
- 决策顺序：用户本次明确要求 → 成品美感与创意 → 构图、字体和完成度 → 对原照片的还原程度。不要为了保留一个无关细节，牺牲整张海报。
- 这些是本版的创作规则。旧案例中“原图结构不能变”“颜色必须不变”等限制，只代表当时任务，不自动沿用到新照片。

## 开始时怎么做

先看照片，简短确定三件事：最有设计潜力的元素、适合的视觉方向、准备先改什么。不要求用户填写一张设计参数表。用途、标题、风格等非关键条件未给时，自主提出合理方案并继续。

用户要求实际制作时，执行生成和编辑；只要本Skill、方案或提示词时，交付对应文件或文字，不启动生图。

未指定模型时，优先当前可用的Image图片模型，目标2K；指定可灵等模型时遵从。比例按用途决定，未指定可从3:4竖版海报开始。选择工具实际支持的规格，不虚构参数或功能。

## 先决定视觉想法

不要从“加什么滤镜”开始。先决定这张图最值得做的变化：

| 照片或画面的问题 | 可以采用的设计动作 | 判断结果 |
|---|---|---|
| 普通、没有记忆点 | 放大一个有趣形态，改变观察角度、尺度或语境 | 有一个能说清楚、也能一眼看到的创意 |
| 主体很小、背景很乱 | 抠出主体、删减背景、重排位置，必要时换场景 | 视线集中，画面有清楚的主次 |
| 画面太平 | 强化透视、前后遮挡、体积与真实阴影；按需让平面形态变成立体 | 空间关系明显，主体与背景分离 |
| 所有元素一样突出 | 只让一个元素改变颜色、大小、清晰度或位置 | 焦点明确，其他元素愿意退后 |
| 字体普通、与图片无关 | 改字形、比例、排列，或让文字进入适合的物体材质 | 标题有个性，仍然好读，且与主题有关 |
| 素材本身有线条和纹理 | 提炼轮廓、几何、印刷底纹或局部切片 | 这些处理参与构图，而非只是装饰 |
| 照片松散、没有秩序 | 建立对齐与留白；必要时把主元素放大、裁切或变形 | 信息密度有变化，画面完整且有节奏 |

每张先抓一个主要创意。可以组合多种方法，但它们应服务同一视觉方向，不把所有效果同时塞进去。

## 风格怎么选

自然数字拼贴与高反差摄影构成是优先考虑的两条路线，尤其适合建筑、树和叶片；它们不是每张照片的必选模板。用户想要简约、前后变化直观时，减少元素，用一个主要改法建立差异。

| 路线 | 适合的素材与目标 | 关键做法 |
|---|---|---|
| 自然数字拼贴 | 树叶、花草、天空、建筑色光；想把自然素材做得鲜活、有层次 | 摄影主视觉、低信息底纹、少量切片与字形分工，用尺度和遮挡形成联系；可以重排、调色和重绘 |
| 高反差摄影构成 | 建筑、楼梯、门框、树干、轮廓强的日常物体；想突出力量与结构 | 强明暗主图、安静留白、少量色彩焦点、大字构成；允许删减结构、夸张透视和尺度 |
| 极简摄影与字体 | 主体轮廓好、需要清楚展示单一变化 | 一个强主角、一套有性格的字体、明确比例与大留白；不是缩小照片后在上面加字 |
| 物体与材质文字 | 水果、食物、陶器、金属，或需要趣味的文字主题 | 雕刻、压印、毛绒、食物等材质与字形结合，做对体积、接触、光向和表面关系 |
| 摄影与印刷拼贴 | 花朵、街头物件、活动氛围；需要节奏与能量 | 分色、局部半调、重复与错位、跨边界排版；清晰区与处理区分开 |
| 国风拓印 | 枝叶、鸟、灯影、屋檐及偏诗意主题 | 墨色块面、受墨变化、纸底留白与有节奏的书写字形 |
| 柔焦、双色半调、木刻、像素故障 | 主题明确需要这些气质时使用 | 先解决构图，再按工艺组织局部效果；不因已有案例就强行套用 |

多方案要在创意、构图或视觉语言上有实质差异。不要把同一张海报只换几个底色，称为多个设计方向。只要求一张时，先完成最适合的一条路线。

## 多步制作与叠加

允许多轮生成、多种编辑叠加，也允许分支制作后合成。**每一轮都应让画面更好，而不是只让画面更复杂。** 根据照片和结果安排步骤，不规定每次必须生成相同数量。

### 第一步：重构主视觉

从原照片出发，把最有潜力的部分变成能撑起海报的主角。

- 按需要去杂物、抠主体、换背景、改光色、夸张比例或透视、改变形态、重绘、增加与主题有关的创意关系。
- 同时考虑主角大小、位置、方向和文字需要的空间。主视觉阶段也可以处理初步构图，不必先保留一张平庸构图再补救。
- 本轮主要解决主体和视觉想法。需要独立材质字或底纹时，可先不加完整海报文字。
- 查看真实结果：主角是否有吸引力、轮廓是否有力、空间与光影是否成立。主视觉不成立，就改这一轮，不急着叠标题。

### 第二步：建立构图与层次

选择适合这张图的做法，而不是机械建立所有图层。

- 用尺度、裁切、前后遮挡、位置、色彩和疏密安排主次。
- 需要底纹、摄影切片或独立字形时，分别制作合适的素材，再合成；简约方案可以直接在主视觉上安排空间。
- 多步叠加时明确每层的作用：主图负责焦点，辅助形态负责节奏，底纹负责气氛，文字负责主题与秩序。没有作用的元素删掉。
- 让处理过的区域与安静、清晰的区域有对比。不要用满图细节掩盖空洞的构图。

### 第三步：字体与完整排版

- 根据照片的形态和主题设计标题，选择合适的字形、粗细、长宽比例、字距与排列。
- 标题可以巨大、拉长、倾斜、跨边界、局部遮挡，也可以具有物体材质；使用哪种方式取决于画面，不是每张都做材质字。
- 主标题、辅助短句和小字有明显层级。小字放在安静区域；不为“像专业海报”塞入无意义的假日期、假参数或说明文字。
- 字体与主图共同构图。若只是矩形照片上方放一行标题，继续寻找更有力的比例、排列或空间关系。

### 第四步：看图精修，必要时换方向

查看成品后找最影响美感的一两项，再做有针对性的下一轮：主体不突出就改比例或明暗，标题无聊就改字形，空间太平就改透视或遮挡，画面太乱就删减和重排。

构图和主视觉已经无力时，回到干净原图或合格主视觉重新设计；不要靠继续加颗粒、边框、小框、线条或模糊拖着走。合格结果可以保留，真正失败的方向可以放弃。

## 两条常用的分支方法

### 自然数字拼贴

1. 从原图提取或重构一份低信息底纹，留出主图与标题空间。
2. 另从原图制作有吸引力的摄影主视觉；可以改色、去背景、调整枝叶或建筑组合，按设计需要重绘。
3. 按需制作独立标题字形或少量主题图形。
4. 合成时让摄影、底纹与文字在尺度和层序上发生关系。局部切片、色散、网点都只在需要的位置使用；不必全部加入。

底纹和摄影主视觉通常是独立分支，避免把已经粗糙化的底纹继续重画成摄影主体。

### 高反差摄影构成

1. 把主体处理成明暗有力量、轮廓清楚的摄影主视觉；必要时先简化背景与结构。
2. 独立组织少量色彩焦点、几何底图或摄影细节；如果简约构图不需要，省掉这一层。
3. 合成主视觉与标题，通过放大、裁切、留白和遮挡完成海报。黑白与彩色比例随照片决定，不固定某一种色板或色数。

分支步骤是方法选择，不是强制工序。只要有助于结果，也可以使用连续编辑路线。

## 连续编辑时保持画面干净

- 多轮可以承接上一轮的合格结果，不要求每次回到原照。整体推翻重做时，优先使用原图或叠加次数较少、细节较干净的输入。
- 每张输入都说明用途：原照提供素材，过程稿承接构图，字形图提供文字效果。只上传必要的图，避免多张成品互相干扰。
- 精确调整小字、边缘或一个局部时，优先局部编辑；工具允许时用蒙版或非生成合成保留其他区域，不承诺生成式改图能让框外逐像素不变。
- 细节集中在主体与视觉焦点；天空、墙面、纸底和阴影等大区域按风格保持连续、干净。用户需要颗粒或粗粝时，保留合理尺度的材质，不把整个画面磨平。
- 可以调色、做双色或进行整体色彩设计，但要保住明暗层次与焦点。避免一层发灰、发白的半透明色罩，把整张图压平。
- 透明素材要确认真实透明通道；棋盘格图案不等于透明背景。

## 每轮指令写清什么

把审美要求落实成具体改法，至少说清：当前目标、各输入作用、主要变化、需要延续的成功设计、精确文案与输出形式。

可按下面的结构写，发送前填入当前照片的具体内容，删除不适用的项目：

> 使用这张照片制作〔本轮主视觉／构图稿／完整海报〕。这次的视觉想法是〔能看见的创意〕。对〔主体或区域〕进行〔具体编辑〕，形成〔比例、透视、光影或材质关系〕。原照片可以按设计需要重构；本次必须保留的是〔仅用户明确要求的内容〕。已经成功的〔构图、字形或区域〕继续保留。标题使用〔准确文字〕，安排在〔位置及层级〕。输出〔实际支持的比例与规格〕，不要额外的教程标注、占位文字或外部样机。

不要只反复写“高级、惊艳、精致”。例如把“更有设计感”落实为“只保留一片巨大叶子，叶缘跨过标题，背景留白，小字沿同一条轴线对齐”。例子解释空间关系，不自动成为下一张图的固定模板。

## 以成图判断美感

每轮必须查看图片，而不只是读模型回复。最终检查以下几项：

1. **主视觉**：缩小看，是否马上知道看哪里？有明确的形态、对比或创意吗？
2. **构图**：主角、标题、留白是否互相配合？疏密和尺度有没有变化？
3. **字体**：字形是否适合主题，有性格且好读？大小层级是否清楚？
4. **质感与颜色**：光影、材质和色彩是否协调？有没有脏纹理、过锐边缘、色罩或多余细节？
5. **整体完成度**：是否只停留在修照片或加字？每个辅助元素是否都有存在的理由？

看不出主要设计变化、主图与文字争抢、越改越脏时，继续解决对应问题；不因完成了预定步骤就宣布效果好。好看仍需要人的判断，不承诺任何照片都能一次成功。

## 交付与操作边界

- 保留原照片、真正执行过的关键过程稿与最终海报；对照时写清原图、过程和成品。生成后反推的修改前图，明确标注，不能冒充真实过程。
- 多版按实际风格分别展示，保持各自画幅；除非要求，不把海报套进室内相框、手机或其他样机。
- 保存实际提示词、输入、模型、尺寸和可见费用。按用户授权与工具规则控制生成次数；已正确的结果复用，排队只等原任务，不重复提交。
- 比较不同模型时，两侧从同一原始素材及同一任务要求独立制作，不把一个模型的成品输入另一个模型来冒充独立结果。
- 风格参考用于理解设计思路，不照搬其主题、文案、构图和配色组合。未经本次授权，不把他人的参考成片或截帧作为生成输入。
- 本Skill负责设计方法，需要配合当前环境可用的生图或编辑能力。只有文件检查通过时，不能宣称这版规则已经重新完成了生图实测。

## 使用方式

上传本文件和照片后，可以这样说：

> 按黄白设计，把这张随拍照片做成好看的海报。可以大幅编辑原照片，以美感为先，按需要多轮生成和叠加修改，保留原图、关键过程和成品。

在支持Skill的助手中安装后，也可直接调用 `$huangbai-design`。
