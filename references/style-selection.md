# 按照片选择风格

用户主推自然数字拼贴、高反差摄影构成，尤其适合建筑、树和叶片。双色半调、柔焦、木刻、像素故障保留为备选，不因已有案例就优先套用。指定风格优先。

| 照片特征 | 优先路线 | 判断与取舍 |
|---|---|---|
| 叶片、树冠、花草、云层，有值得保留的原色和纹理 | 自然数字拼贴 | 原色摄影负责鲜活感，复印底纹承接边缘；建筑不照搬点阵花朵 |
| 梁柱、门框、楼群、桥、树干、叶片等轮廓清楚，几何或明暗关系强 | 高反差摄影构成 | 黑白主体与原色切片对比；建筑结构真实，叶脉保留摄影层次 |
| 建筑既有强结构又有迷人色光 | 两种主推风格均可 | 主打结构选高反差；主打色光气氛选自然数字拼贴；多版应有不同视觉逻辑 |
| 背景杂、主体可提取 | 高反差摄影构成 | 清晰主图与低信息底纹分工，不把杂乱背景也塞满 |
| 模糊夜色、光斑、阴影、天空，重点是氛围 | 柔焦弥散（备选）或自然数字拼贴 | 留一处清晰锚点，不能全图糊掉；人脸与文字不跟着模糊 |
| 水果、面包、金属、陶器，曲面与质感清楚 | 材质文字 | 字进入真实表面；先做好凹刻或烙印再排外部标题 |
| 花朵或日常物件轮廓鲜明，适合活泼高能量传播 | 多层摄影拼贴的网印路线 | 分色、半调、跨框和字体对比；细字不全部网点化 |
| 枯树、旧物等适合记忆、档案或数码主题 | 多层摄影拼贴的记忆界面路线 | 窗口服务主题，不把所有风景套成电脑界面 |
| 飞鸟、树枝、灯笼、屋檐，主题偏东方诗意 | 国风拓印 | 干墨、留白与书写，不能只转黑白 |
| 桂花、银杏、秋树，轮廓细碎、气氛轻盈 | 秋日颗粒与描边 | 摄影、细颗粒、实色和空心线分工；不用刀痕代替颗粒 |
| 剪影、简洁明暗，主题需要印刷感 | 双色半调网屏（备选） | 网点塑造明暗，细结构与字仍可读 |
| 枝干、叶缘、山石方向鲜明，主题需要版画感 | 单色木刻版画（备选） | 用有方向的刀痕与受墨缺口，不用摄影噪点冒充 |
| 屏幕、霓虹、运动切片、数字记忆或明确故障要求 | 复古像素故障（备选） | 控制局部像素、扫描错位，保留清晰主体 |
| 人物生活照、室内随拍 | 按轮廓与环境，通常高反差或克制摄影拼贴 | 保留身份、姿态和服装，不换脸或改身体；私密背景不扩写为虚构事件 |

未指定风格时简短解释选择后继续，不先让用户选择全部风格。严重缺损只能利用仍可辨认的证据，不假装精确恢复。用户只给照片时可拟短标题。

示例说明：“这张楼梯有清楚的斜线，走高反差构成。分别处理黑白结构与原色细节，再组合大字和前后遮挡。”随后要实际执行所述阶段。
