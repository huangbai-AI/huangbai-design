# 多步制作、改稿与交付

## 建立本张照片的设计目标

记录用途、比例、视觉想法、风格、模型及用户明确要求保留的内容。原照可以裁切、去杂物、换背景、调色、变形、重绘与重构；不要自行把原照片的结构、原色和背景全部锁定。颜色与形态可从原照出发，也可为主题重新设计；主图、底纹、切片和字形按需要分工，不为凑图层而加装饰。

## 真正执行多个阶段

| 阶段 | 输入与输出 | 是否实质改变画面 |
|---|---|---|
| 看图与方案 | 原图→文字计划、精确文案、层的职责 | 否 |
| 主体/摄影处理 | 原图→裁切、抠图、重构、换背景、调光色、拓印或材质主体 | **是：生成/编辑** |
| 底纹/构图分支 | 原图为主→同源底纹、切片底图或无标题构成稿 | **是：生成/编辑** |
| 独立字形分支（按需） | 精确文字→字形或少量装饰素材 | **是：生成/编辑** |
| 合成排版 | 原图提供素材、本模型必要过程稿用于合成→完整海报 | **是：生成/编辑/图层合成** |
| 有缺陷才局部修改 | 原图、相关层、必要成品与范围→修正版 | **是：局部编辑/蒙版/文字调整** |
| 过程展示 | 已有图片→对照页 | 只改展示排列，不改海报像素 |

自然数字拼贴常用素材分支后合成，高反差常用主体、底图与字形分层；也可以采用主视觉→排版→精修的连续编辑。拆分由工艺与成图决定，可多轮叠加、删减或重做，不规定每张必须使用相同次数。每轮都查看真实图片，以美感和完成度判断是否进入下一步。

## 输入选择与干净度

- 主体、底纹可以各自从原照获得时分别处理，避免整张海报连续重画。
- 连续编辑时，原照提供素材，最近合格阶段承接已完成设计；只有用户明确要求保留的身份或结构才锚定。逐张说明作用，避免模型把原图误当另一个照片窗口。
- 合成只提供必要层。案例图和其他模型的图不是默认输入。工具限制图片数量时，用确定性蒙版/透明图层预合成已完成素材，再做必要排版；如实记录，不编造接口。
- 透明需求验证实际透明通道；棋盘格不算透明。若只能得到纯底素材，可用去背或蒙版提取并看边缘，记录此操作。
- 细小文字、边缘和色点优先局部修；必要时非生成蒙版贴回，保留未改区域。允许整体调色、双色与材质处理；避免发灰色罩、无目的降透明度和满图噪点把画面压平，不把设计限制为三种颜色。
- 默认目标2K，工具未支持时说明实际规格。旧1K低画质案例不意味着新任务默认低画质。

## 每步提示词

先读相近真实案例的完整提示词，再写当前照片的指令。明确用途、视觉想法、每张输入作用、本步做什么、明确要求保留什么、材质区域和输出形态。例如：

```text
本次只制作【风格】的【当前阶段】，不是一次完成所有步骤。
输入1【原照】负责【提供本次创作素材】；输入2【本模型过程图】负责【承接构图，确有需要才提供】。
原照片允许重构；本次必须保留【仅用户明确指定的内容，没有则删除此项】。
只做【材质/底纹/构图等本步操作，写明区域、尺度、前后关系】。
已完成的【明确区域或效果】保持不动，暂时不加【下一阶段的文字或装饰】。
【指定区域】保留干净明暗；避免【这条风格的常见偏差】。
输出【比例和规格】单张【独立素材/平面海报】，无样机、无步骤说明和占位字。
```

合成时逐一指定各素材职责、层序、精确标题、焦点和留白。用具体空间关系代替重复“高级、精致”。上面是写法结构，不能保留加号或占位内容直接发送。

## 失败时修哪里

| 问题 | 回退位置与动作 |
|---|---|
| 用户明确要求保留的内容被改掉，或重构后的形体、光影不成立 | 修正对应主体分支；允许的创意变化不因偏离原图而被判错 |
| 全图色罩、灰雾、明暗被压成一层 | 重建明暗与色彩焦点，去掉让画面发灰的覆盖策略 |
| 只剩照片加标题，切片像相册 | 回构图，改尺度、裁切、跨界与遮挡，不靠更多装饰 |
| 颗粒太密、纹理混脏、枝叶糊 | 收缩材质区域、减弱非焦点细节，留清晰摄影锚点 |
| 字遮死主体、难读、大小无层级 | 只改字形与位置、字距、大小、前后关系 |
| 建筑无故出现花朵、星星、电脑窗口 | 移除案例专属装饰，改用本图同源图形 |

每轮先修最影响美感的一两项。持续不成立时，回到干净原照或合格分支，换主视觉、构图、方法或工具，不无限叠特效；已经好看的部分优先保留。费用按已有授权，失败如实说明，不包装成成功。

## 交付

原图→关键素材/构图稿→成品，有分支就如实展示分支。多版分别标风格，按原比例展示，未经要求不加样机。保存模型原版与另存修改版。用户指定文档交付时按原版式上传真实图片，再读回核验；仅制作技能不自动改外部文档。
