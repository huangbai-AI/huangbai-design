# 保存真实过程

每个案例独立目录，保留原图、阶段提示词、模型原版、必要局部修改版、成品与对照。留到当前项目，用户私图不自动加入技能。

```text
案例名/
  原图.原扩展名
  01-主体处理/提示词.txt、输出.png
  02-底图处理/提示词.txt、输出.png
  03-合成排版/提示词.txt、输出.png
  过程记录.json
  原图与成品对照.jpg
```

按真实工艺调整目录和阶段数；不存在的阶段不建假记录。原版保留，展示缩略图另存。

每次记录：阶段、操作类型、是否实质改变画面、输入文件及作用、是否本模型生成、完整提示词、输出文件、实际模型与尺寸、任务编号（如果返回）、实际检查、修改原因、实际费用（如果返回）。没有的信息写未知，不编造版本、积分和任务编号。

```json
{
  "案例": "本次主题",
  "风格": "高反差摄影构成",
  "原图来源": "用户当次提供",
  "步骤": [{
    "阶段": "黑白主体",
    "操作类型": "图片编辑",
    "实质改变画面": true,
    "输入": [{"文件": "原图.jpg", "作用": "真实主体来源", "来自本模型": false}],
    "提示词文件": "01-主体处理/提示词.txt",
    "模型": null,
    "实际尺寸": null,
    "任务编号": null,
    "输出": "01-主体处理/输出.png",
    "检查结果": "填写实际观察",
    "修改原因": null,
    "实际费用": null
  }]
}
```

模型对照记录共享原图与文案、每阶段目标、必要接口适配、各侧独立输入与输出；必要时记录文件校验以发现串图。保留原水印，后期版单列。已有案例的真实提示词与路线见 [案例索引](cases.md)，后写通用方案不能冒充旧图的实际过程。
